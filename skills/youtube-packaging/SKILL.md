# YouTube packaging

- **Thumbnail.** Start with the image that makes the premise understandable at phone size. Pull an actual payoff frame when the clip already has a strong reveal, or use ImageGen for a matching concept. Keep the wording short and let the opening seconds deliver the same premise. Describe the design choice without promising views.
- **Channel banner.** Use the existing wordmark and an approved art reference. Compose the name and defining character feature inside the central crop, leaving the outer artwork for wide displays. Compare the export and a simulated mobile crop. Check the current dimensions and file limit in [YouTube's branding guidelines](https://support.google.com/youtube/answer/10456525).
- **Comment reply.** Match the user's casual voice, answer the strongest claim, and keep the reply short. If a timestamp matters, check the uploaded revision or its matching captions. When a comment cites a leak, distinguish what it actually shows from the theory presented in the video. Provide a draft unless the user asks to post.
