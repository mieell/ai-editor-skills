# AI Editor Skills

Reusable Codex skills for the VIDEO AI STORY RANDOM project.

| Skill | Use it for |
| --- | --- |
| [Channel research](skills/channel-research/SKILL.md) | Analyze a YouTube channel, verify uploads, and turn observations into production direction. |
| [Shorts production](skills/shorts-production/SKILL.md) | Write and storyboard Shorts, generate art, animate shots, and choose a local fallback. |
| [Video finishing](skills/video-finishing/SKILL.md) | Edit takes, sync captions, mix audio, and verify exports. |
| [YouTube packaging](skills/youtube-packaging/SKILL.md) | Make thumbnails and banners and draft audience replies. |

Copy the individual skill folders into your Codex skills directory or a project's `.agents/skills/` directory. Each folder is independently usable. The production skill also documents the channel-specific choices for doomv12, Flipbook, and Timeline Anomalies.
